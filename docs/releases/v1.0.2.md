# KR Mycelia Memory v1.0.2

Dieses Patch-Release korrigiert die Zuordnung und Wiedergewinnung von Inhalten
aus überwachten Projektordnern.

## Korrigierte Datei- und Projektzuordnung

- Jede überwachte Datei wird über einen kanonischen absoluten Quellpfad
  identifiziert und bei Änderungen im selben DAD-Datensatz fortgeschrieben.
- Der Collector speichert `watch_root`, `project`, `source_path`,
  `source_version`, den Inhaltsprüfwert und die zuletzt hinzugefügte bzw.
  entfernte Textregion.
- Sammelordner erkennen den ersten Unterordner als Projekt. Damit gehört
  `H:\mc_memory_test\MDraft\README.md` eindeutig zu `MDraft`.
- Der Hintergrundabgleich entfernt Datensätze nicht mehr vorhandener Dateien
  und historische Duplikate derselben Quelle.
- Memory Chat und die allgemeine assoziative Suche priorisieren Projekt,
  Dateiname und Pfad vor beiläufigen Volltexterwähnungen.
- Lange Dateien liefern einen Ausschnitt um den tatsächlichen Suchtreffer,
  statt ausschließlich den Dateianfang an das lokale Modell zu senden.

## Betrieb

Erfassung bleibt nach Installation in der vom Benutzer gewählten Einstellung.
Ist sie ausgeschaltet, beginnt kein Ordnerscan. Nach dem Einschalten startet
die Dateiüberwachung sofort; der Bestandsabgleich läuft abbrechbar im
Hintergrund. Das Entfernen einer Ordnerfreigabe löscht weiterhin keine
historischen Erinnerungen, weil eine Freigabeänderung kein Löschauftrag ist.

## Qualität

- Windows-x64-Release-Build erfolgreich.
- 48/48 registrierte Tests bestanden.
- Dedizierte Regression für den MDraft/KALYX-Zuordnungsfehler enthalten.
