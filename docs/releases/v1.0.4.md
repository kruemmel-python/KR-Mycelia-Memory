# KR Mycelia Memory v1.0.4

Dieses Wartungsrelease behebt die irreführende Explorer-Meldung
**„Gedächtnissuche fehlgeschlagen oder Dienst nicht erreichbar“** bei großen
lokalen Gedächtnisbeständen.

## Ursache

Der Dienst war erreichbar und lieferte eine gültige Antwort. Sobald die
Trefferliste jedoch größer als 64 KiB wurde, las der Client nur den ersten
Pipe-Block. Das abgeschnittene JSON wurde anschließend als Verbindungsfehler
interpretiert.

## Korrektur

- Vollständiges Lesen mehrteiliger Named-Pipe-Nachrichten.
- Kontrollierte Antwortobergrenze von 32 MiB.
- Kompakte Explorer-Listen statt vollständiger Inhalte aller Treffer.
- Automatisches Nachladen des vollständigen Datensatzes beim Anklicken.
- Neuer installierter Explorer-End-to-End-Test.

## Nachweis

- Reale Listenantwort: 163.864 Byte, vollständig empfangen und validiert.
- Vollständiger Datensatz anschließend erfolgreich über `memory.get` geladen.
- Installierter Explorer-End-to-End-Test: Exitcode 0.
- DAD-Persistenz- und Dienstneustarttest: bestanden.
