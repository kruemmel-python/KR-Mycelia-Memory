# KR Mycelia Memory v1.0.1

Dieses Patch-Release ergänzt die verbindliche Lizenzierung des Projekts. Die
Anwendungsprogramme sind funktional identisch mit v1.0.0.

## Lizenzierung

- KR Mycelia Memory wird unter der **PolyForm Noncommercial License 1.0.0**
  bereitgestellt.
- Der vollständige offizielle Lizenztext ist im Release-Paket als `LICENSE`
  enthalten.
- Der Installer kopiert `LICENSE`, `README.md` und `CHANGELOG.md` in das lokale
  Programmverzeichnis.
- Die Lizenz gestattet die in ihr beschriebenen nichtkommerziellen Zwecke. Eine
  kommerzielle Nutzung ist nicht gestattet.

## Installation

1. `KR-Mycelia-Memory-Windows-x64-v1.0.1.zip` herunterladen.
2. Das ZIP vollständig in einen neuen Ordner entpacken.
3. PowerShell im entpackten Ordner öffnen.
4. Installation ausführen:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Der Installer prüft die kopierten Dateien, die DAD-Persistenz und den
Hintergrunddienst. Autostart und Kontexterfassung bleiben standardmäßig
deaktiviert.

## Integritätsprüfung

Die separat veröffentlichte Datei `SHA256SUMS.txt` enthält die SHA-256-Prüfsumme
des ZIP-Archivs:

```powershell
Get-FileHash .\KR-Mycelia-Memory-Windows-x64-v1.0.1.zip -Algorithm SHA256
```
